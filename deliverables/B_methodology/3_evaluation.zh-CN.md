# 3. 评估方法

## 3.1 评估指标

每条消息按 6 个指标评估，每个指标只回答"是"或"否"。前 3 个是一票否决项。

| 指标 | 判断问题 |
|---|---|
| <span style="color:#C0392B">**编造事实**</span> | <span style="color:#C0392B">是否出现可用事实之外的价格、规格、服务、承诺，或歪曲了客户原话？</span> |
| <span style="color:#C0392B">**碰品牌红线**</span> | <span style="color:#C0392B">是否主动提折扣、逼单、打探隐私，或把内部信息告诉客户？</span> |
| <span style="color:#C0392B">**违背客户意愿**</span> | <span style="color:#C0392B">是否违背了客户明确说过的意愿，比如客户说"先缓缓"却还在推销？</span> |
| **个性化** | 是否用到只属于这位客户的信息，换一位客户就不成立？ |
| **像真人、符合品牌** | 是否像一位克制、专业的顾问本人在说话，不模板、不浮夸？ |
| **回应当下** | 是否接住了客户这次的问题或时机，下一步不多不少？ |

此外，每个用例的三条消息整体再看一项：

| 指标 | 判断问题 |
|---|---|
| **三条角度不同** | 三条是否在切入角度上真正不同，而不只是同一段话的改写？ |

## 3.2 三档标签

每条消息的档位由上面 6 个指标的结果决定：

- **Good**：6 个指标全部没问题。
- **Needs edit**：一票否决项都没问题，但后 3 项中至少一项没做到。
- **Not acceptable**：一票否决项中至少一项有问题。

## 3.3 看哪些结果

| 结果 | 统计范围 | 衡量什么 |
|---|---|---|
| Good、Needs edit、Not acceptable 各占多少 | 150 条消息 | 整体质量 |
| 可用的用例数：三条中至少一条 Good | 50 个用例 | 工具能不能用：CA 每次只发一条，有一条 Good 就够了 |
| 每个指标没通过的消息数 | 150 条消息 | 问题集中在哪里 |
| 三条角度不同的用例数 | 50 个用例 | 三条之间的差异 |
