# 0. 先虚构一个品牌

题目没有给品牌，所以第一步是自己造一个：LACAZE。它 1923 年创立于巴黎，从旅行皮具和马具工坊起家，后来只做手袋。它的调性是克制、经典、重工艺，不打折，不比价，也不促销。产品线只有 6 款，价格从 3.5 万到 38 万元，其中最贵的两款要攒够消费才能买。这样设定，是因为真实的奢侈品顾问每天都会遇到这类处境：客户想要的包不是想买就能买，客户嫌贵时顾问又不能降价。

客户按在 LACAZE 的累计消费分成五层。层级决定客户能买哪些款、能参加哪些活动，但顾问从不对客户提起：

| 层级 | 累计消费 |
|---|---|
| Unclassified | 尚无购买 |
| Prospect | 5 万元以下 |
| Core | 5 万元及以上 |
| VIC | 25 万元及以上 |
| VVIP | 100 万元及以上 |

围绕这个品牌，我还准备了一份小小的"门店数据"：10 位客户和他们的购买记录、每款包的详细规格、几场门店活动、门店能提供的服务和定价政策。工具的输入只有客户 ID、产品 ID 这类标识，具体信息都要它自己去这份数据里查。这样做，是想让每条消息里的价格、尺寸都有出处，而不是靠模型自己记，或者靠它想象。
