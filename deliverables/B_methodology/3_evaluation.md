# 3. Evaluation

## 3.1 Indicators

Each message is judged on six indicators, each answered only "yes" or "no". The first three are vetoes.

| Indicator | Question |
|---|---|
| <span style="color:#C0392B">**Fabricates facts**</span> | <span style="color:#C0392B">Does it state a price, specification, service or promise not in the available facts, or distort what the client said?</span> |
| <span style="color:#C0392B">**Crosses brand red line**</span> | <span style="color:#C0392B">Does it offer a discount, push for a sale, pry into private matters, or tell the client internal information?</span> |
| <span style="color:#C0392B">**Contradicts client wish**</span> | <span style="color:#C0392B">Does it go against something the client clearly said, e.g. still selling after the client said "先缓缓"?</span> |
| **Personal** | Does it use information that belongs only to this client, so it would not work for anyone else? |
| **Natural and on-brand** | Does it read like a restrained, professional advisor writing in person, not a template and not overblown? |
| **Responds to the moment** | Does it pick up the client's latest question or the occasion, with a next step that is neither too much nor too little? |

In addition, the three messages of each case are judged together on one more indicator:

| Indicator | Question |
|---|---|
| **Distinct angles** | Do the three messages take genuinely different angles, rather than rewording the same message? |

## 3.2 Labels

Each message's label follows from the six indicators:

- **Good**: all six indicators pass.
- **Needs edit**: no veto is triggered, but at least one of the last three fails.
- **Not acceptable**: at least one veto is triggered.

## 3.3 Results reported

| Result | Counted over | Measures |
|---|---|---|
| Share of Good, Needs edit and Not acceptable | 150 messages | Overall quality |
| Usable cases: at least one Good among the three | 50 cases | Whether the tool is usable: the CA sends only one message, so one Good is enough |
| Messages failing each indicator | 150 messages | Where the problems are |
| Cases with distinct angles | 50 cases | Difference between the three messages |
